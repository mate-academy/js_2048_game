# Getting Started
Follow these steps to set up the project locally

1. Clone the repo
```
git clone https://github.com/GabrielSpelchuk/js_2048_game.git
cd js_2048_game
```
2. Install dependencies
```
npm install
# or
yarn install
```
3. Run the project locally
```
npm start
# or
yarn start
```
