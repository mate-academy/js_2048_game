# 2048 Game

[🎮 Play the Game](https://nex1994.github.io/js_2048_game/) • [📂 GitHub Repository](https://github.com/nex1994/js_2048_game/tree/develop)

A web implementation of the classic **2048 puzzle game**, where players combine matching tiles to reach the number 2048.

---

## ✨ Features
- 🎲 **Classic 2048 Gameplay** — Combine tiles by moving them in four directions.  
- 📊 **Score Tracking** — Keeps track of the current and best score.  
- 🎨 **Smooth Animations** — Visual feedback when tiles merge or move.  
- 🔄 **Restart Option** — Reset the board and start again at any time.  
- 📱 **Responsive Design** — Playable on desktop and mobile.  

---

## 🛠️ Tech Stack
- **JavaScript (ES6)** for game logic  
- **HTML5** for structure  
- **CSS3** for styling and animations  
- **GitHub Pages** for deployment
