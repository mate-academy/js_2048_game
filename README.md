# 2048 Game

A browser implementation of the classic [2048](https://play2048.co/) puzzle game, built with vanilla JavaScript. Merge matching tiles with the arrow keys to reach 2048.

## Live demo

- [Demo](https://proninamariia.github.io/js_2048_game/)

## Technologies used

- HTML5
- Sass (SCSS)
- Vanilla JavaScript (ES modules)
- Jest for unit tests

## Core features

- Classic 4x4 2048 gameplay controlled with arrow keys
- Score tracking, win and game-over states
- Start / Restart button that resets the board
- A short pop-in animation for new and merged tiles

## Setup instructions

```bash
npm install
npm start       # local dev server
npm test        # run unit tests
npm run build   # production build
npm run deploy  # deploy to GitHub Pages
```
