# 2048 Game

Browser version of the 2048 puzzle, built with vanilla JavaScript.

- [DEMO LINK](https://carvalhoryahn-alt.github.io/js_2048_game/)

## How to play

Use the arrow keys to slide the tiles. Equal tiles merge into one,
and you win when a 2048 tile appears.

## Built with

- JavaScript (ES6 classes)
- HTML and SCSS
- Jest for tests
