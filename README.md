# 2048 Game

An interactive browser-based implementation of the classic 2048 puzzle game, built with JavaScript, HTML, and SCSS.

The game challenges players to combine numbered tiles to reach 2048. It features keyboard controls, tile merging, score tracking, random tile generation, and automatic win and game-over detection.

## Technologies Used

- HTML5
- SCSS
- JavaScript (ES6+)
- DOM Manipulation
- Object-Oriented Programming (OOP)

## Features

- Classic 2048 gameplay on a 4×4 grid
- Keyboard controls using arrow keys
- Tile movement and merging in four directions
- Automatic generation of new tiles after valid moves
- Score tracking based on merged tile values
- Win detection when a tile reaches 2048
- Game-over detection when no valid moves remain
- Start and Restart functionality
- Dynamic tile styling based on tile values
- Separate game logic and user interface

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Go to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

## How to Play

1. Click **Start** to begin the game.
2. Use the arrow keys to move tiles across the board.
3. When two tiles with the same number collide, they merge into one.
4. Each merge increases your score.
5. Continue combining tiles until you reach **2048**.
6. The game ends when no valid moves are available.
7. Click **Restart** to start a new game.
