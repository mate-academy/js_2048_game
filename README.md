# 2048 Game

A browser implementation of the classic 2048 game built with JavaScript. The goal is to combine tiles with the same values until you reach the 2048 tile. The game includes score tracking, win and game-over states, keyboard controls, and restart functionality.

## Live Preview

🔗 https://maksymivivan2000-dotcom.github.io/js_2048_game/

## Design Reference

🔗 https://play2048.co/

## Technologies Used

* HTML5
* SCSS
* JavaScript (ES6+)
* Git & GitHub

## Getting Started

### Clone the repository

```bash
git clone https://github.com/maksymivivan2000-dotcom/js_2048_game.git
cd js_2048_game
```

### Install dependencies

```bash
npm install
```

### Run the project locally

```bash
npm start
```

## Features

* Classic 2048 gameplay
* Keyboard arrow controls
* Random tile generation (2 and 4)
* Score calculation
* Win detection (2048 tile)
* Game Over detection
* Restart functionality
* Responsive game board
